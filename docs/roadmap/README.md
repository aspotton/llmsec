# Roadmap

The implementation starts with a small text-security runtime and grows in layers rather than attempting the full architecture at once.

## Suggested sequence

1. V0.1 text inspection core, deterministic detectors, bootstrap injection detector, tests, CI, docs.
2. Policy/configuration improvements and thin framework integrations.
3. Tool/action reference monitor and typed effects/capabilities.
4. Provenance, authority, data lineage, and source-influence controls.
5. Project-trained compact security model and ONNX runtime.
6. Long-context/RAG aggregation.
7. Memory security and persistence rules.
8. Streaming inspection and output holdback.
9. Adaptive evaluation, community bypass intake, and advanced open-model role-confusion probes.
10. Thin framework integrations, sidecar deployment, and optional LLM Guard compatibility adapters.

The individual roadmap documents capture architectural intent. They are not promises that V0.1 already implements those features.

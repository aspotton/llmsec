# Evaluation philosophy

Security evaluation must measure both attack resistance and utility.

As the project grows, report:

- recall at fixed low false-positive rates;
- per-attack-family recall;
- benign trigger-rich false positives;
- calibration and uncertainty;
- held-out transformation families;
- adaptive attacks targeting the candidate defense;
- long-context and multi-turn attacks;
- end-to-end unauthorized-action success for agent integrations;
- task completion and unnecessary confirmation/blocking rates;
- latency and memory on named reference hardware.

Static benchmark accuracy alone is not a sufficient security claim.
